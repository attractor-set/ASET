# Canonical Seed development area

Status: `BOOTSTRAP_SCAFFOLD_NOT_RELEASED`

This area establishes the authoring and validation architecture for
the next ASET Seed release.

It is not yet a complete extraction of rc11.

## Components

- `source/seed-model.json` — structured canonical source candidate;
- `schemas/` — structural validation;
- `ontology/` — RDF/OWL semantic vocabulary;
- `shapes/` — SHACL constraints;
- `terminology/` — SKOS and TBX terminology;
- `formal/` — formal transition-model work.

The full migration requires requirement-by-requirement traceability
and a new independent audit.
