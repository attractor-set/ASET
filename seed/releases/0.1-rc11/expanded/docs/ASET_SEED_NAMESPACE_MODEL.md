# Namespace model

Context is a normative namespace. Ancestry is not Authority inheritance. Each action belongs to exactly one Context. Cross-context recognition is a chain of Export, local Import Observation, local Verification and local Outcome.

ContextID is derived from parent ContextID and member Genesis digest. Alias is only a live address and may be reused after a branch becomes historical; references and provenance use ContextID. NORMATIVE dependency endpoints must both be ACTIVE.
