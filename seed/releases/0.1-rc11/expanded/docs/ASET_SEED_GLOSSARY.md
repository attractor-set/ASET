# Glossary

- **Trust Space** — one stateful Genesis lineage.
- **Context** — normative namespace with immutable ContextID and lifecycle.
- **Authority** — active institutional POWER in an exact Context and scope.
- **Permit** — bounded authorization for an exact task and success policy.
- **AffectedSiblingSet** — minimal transitive set of active direct siblings normatively depending on a target.
- **Membership withdrawal** — final member-signed exit without successor promise.
- **Context redefinition** — one atomic replacement of an exact affected sibling set.
- **Proposal** — canonical full replacement plan whose digest is signed by every affected member.
- **Live alias index** — mapping containing only ACTIVE Contexts.
- **Historical Context** — WITHDRAWN, SUPERSEDED or TERMINATED Context retained for provenance but excluded from active normative edges.
