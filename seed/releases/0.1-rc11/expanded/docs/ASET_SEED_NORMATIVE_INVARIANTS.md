# Normative invariants

The authoritative list is Section 20 of the specification. The highest-risk invariants are: exact state and local ordinals; derived causal parents; Authority exclusivity; complete effective Verification set; immutable Outcome; active-only normative dependency graph; no standalone exit with an active normative dependant; exact affected-sibling closure; canonical proposal and exact member authorization set; atomic successor mapping; and no cross-context Authority transfer without local recognition.
