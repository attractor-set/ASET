# ASET Seed releases

Frozen release directories are immutable historical evidence. Each release directory contains delivery assets, materialized publications, and—where available—a byte-exact expanded tree for direct review.

The active normative Seed source is `seed/canonical/` at version `0.3.0-alpha.1`. Its semantic baseline is identified by the protected tag `seed-0.3.0-alpha.1-semantic-freeze`.

`seed/releases/0.1-rc11/` remains an immutable historical release bundle. It is retained for provenance and byte-identity assurance; it does not define the active Seed semantics.

Any future semantic release must have a distinct version, exact manifest, checksums, conformance evidence, formal assurance, owner approval, and protected tag. Existing frozen bytes must never be rewritten.
