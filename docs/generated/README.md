# Generated language editions

These files are deterministic derived representations of the complete rc12 release-candidate machine canon in `seed/canonical/source/seed-model.json`.

They must not be edited manually. The canonical machine model, protocol schemas, constraints, requirements, invariants, transitions, and conformance bindings have authority over generated prose. A parity mismatch is a release-blocking failure.

ASET Seed 0.1-rc11 remains the immutable current stable release until rc12 exact release bytes complete every mandatory gate and are separately frozen. The generated rc12 editions therefore have status `RC12_RELEASE_CANDIDATE_READY`, not stable-release status.
