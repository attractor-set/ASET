# Repository assurance

This directory contains **public, non-normative assurance artifacts** that
protect or explain properties of the normative ASET canon without becoming
part of that canon.

Assurance dependencies point inward to frozen normative subjects. Normative
packages do not import or hash these external assurance layers.
