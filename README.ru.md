# ASET

ASET — проект, в котором спецификация предшествует реализации
и определяет её допустимое поведение.

## Состояние репозитория

- ASET Seed 0.1-rc11 сохраняется как неизменяемый исторический выпуск.
- Машиночитаемый канон следующего выпуска Seed находится в разработке.
- Русская, английская и бразильская португальская редакции строятся
  непосредственно из одной канонической модели.
- Эталонная реализация имеет статус кандидата.
- Эксплуатационный статус остаётся `HOLD`.

## Иерархия нормативности

Для выпусков после завершения перехода к канонической модели:

1. машиночитаемая семантическая модель;
2. машиночитаемые ограничения и инварианты;
3. автоматически построенные официальные языковые редакции;
4. пояснительные материалы.

Замороженный выпуск нельзя изменять задним числом.

## Основные каталоги

- `seed/releases/` — неизменяемые выпуски Seed;
- `seed/canonical/` — каноническая модель следующего выпуска;
- `docs/generated/` — автоматически построенные редакции;
- `tools/` — средства проверки и публикации;
- `.github/workflows/` — проверки непрерывной интеграции.
