# ASET

**ASET — Authority-Seeded Evidence Trail.**

ASET — открытая технологически нейтральная спецификация **минимального машиноинтерпретируемого семантического Seed**: машиночитаемого, независимо реализуемого и проверяемого семантического сосуда, операционным ядром которого является распознавание разрешений в границах Authority. Здесь *seeded* означает и происхождение допустимости от явно признанной привязки Authority, и способность той же публичной формы переносить независимо созданную семантику дальше, не наделяя её создателя полномочием признания.

```text
UNKNOWN | ALLOW | BLOCK
```

Только одна уникальная действительная и точно связанная запись `ALLOW`, признанная локальной Authority, разрешает связанный эффект. Отсутствие или конфликт действительного терминального материала даёт `UNKNOWN`; явный запрет — `BLOCK`. Внешний материал сам по себе не создаёт локальную Authority.

## Почему Seed

Seed не предписывает архитектуру приложения или алгоритм эволюции. Это минимальная публичная форма, в которой нормативный смысл остаётся машиночитаемым, достаточно явным для независимой интерпретации, независимо реализуемым и внешне проверяемым. Новые кандидатные формы могут обнаруживаться любым внешним механизмом; порождение, выбор или проверка кандидата не дают этому механизму Authority и не создают приоритета признания.

Поэтому ASET стандартизует **публичную границу эволюции**, а не привилегированный субстрат поиска. См. [роль ASET Seed](docs/architecture/SEED_ROLE.md) и [границу эволюции](docs/architecture/EVOLUTION_BOUNDARY.md).

## Прямые нижележащие проекты

- [ASET Network Extension](https://github.com/attractor-set/aset-network-extension) — технологически нейтральное нормативное расширение ASET Seed для межконтекстного признания.
- [ASET Python SQLite](https://github.com/attractor-set/aset-python-sqlite) — ненормативная эталонная реализация Seed.

Здесь перечисляются только непосредственные нижележащие связи. Транзитивные потомки обнаруживаются через их непосредственные родительские проекты.

Нормативный источник: [канон Seed](seed/canonical/README.md).

## Стандарт совместимости

Опубликованные релизы Seed могут выступать как неизменяемые версионированные стандарты совместимости для независимых реализаций. Первый объявленный baseline — `seed-0.3.0-alpha.2`. Соответствие проверяется внешним ASET conformance runner относительно точной идентичности релиза, canonical package и всех обязательных cases.

См. [ASET Seed Compatibility Standard](standards/seed-compatibility/README.md).
