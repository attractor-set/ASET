# Legacy component extraction

The active ASET repository now contains the minimal Seed specification and its direct assurance
boundary. The former in-tree system composition, component canons, component-only tooling,
component audits and generated component views were removed from the active tree.

The removed corpus remains available through:

1. Git history at source revision `04acffaafcf7de1f81ee83b6c92cbe644ab23cd2`;
2. release asset `ASET-legacy-component-corpus-0.1-rc1.zip`;
3. SHA-256 `e2fd10bbf0d9ab871624ef7347ddc6dd8827607a1b45db238de1fa26364d4587`;
4. separately published extension and implementation repositories.

The machine-readable record is [`EXTRACTION.json`](EXTRACTION.json).

Extraction changes repository organization and assurance scope. It does not change the active
resolution algebra and does not assign semantic precedence to any extracted repository.
