# Governance

ASET currently uses owner-led, specification-first governance.

A normative change requires:

1. a machine-readable proposal;
2. semantic-difference classification;
3. schema and constraint updates;
4. executable conformance cases;
5. adversarial tests;
6. regenerated language editions;
7. independent audit;
8. a new immutable release.

Frozen release bytes are never rewritten.

Experimental work belongs outside frozen release directories.
